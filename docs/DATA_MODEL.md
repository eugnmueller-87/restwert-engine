# Restwert Engine: data model

GENERATED by `python -m restwert.schema` from `restwert/schema.py` (package version 0.3.0). Do not edit by hand.

> THE MODEL ADVISES, DETERMINISTIC CODE DECIDES, A NAMED HUMAN OWNS EVERY THRESHOLD.

Conventions: money `DECIMAL(12,2)` EUR; ratios `DOUBLE`; dates `DATE`; ids `VARCHAR`. 
Every source table ends with `is_synthetic BOOLEAN NOT NULL, source_file VARCHAR`. 
Foreign keys are validated by `schema.validate_frame` and `db.load_csv_dir` (referential check), not by DuckDB constraints.

v0.2: the ten source tables are conformed from the bronze layer of the data lake; see docs/DATA_LAKE.md for feeds, keys and the silver ledger.

## Table groups

| Group | Tables |
|---|---|
| Source (loaded from CSV, `is_synthetic` on every row) | `model_catalogue`, `devices`, `rental_contracts`, `events`, `refurbishment`, `resale`, `supplier_contracts`, `purchase_orders`, `indirect_spend`, `benchmarks` |
| Derived, rebuilt on every run | `device_pnl`, `tco_per_model`, `pnl_aggregate`, `rv_forecast_grid`, `rv_forecast_current`, `rv_forecast_of_record`, `rv_forecast_error_monthly`, `backtest_result`, `advisories`, `decision_queue`, `kpi_values`, `kpi_breakdown`, `contracts_register`, `renewal_calendar` |
| Immutable, append only | `forecast_runs`, `decision_log`, `write_down_ledger`, `runs` |

Referential checks at load: `devices.model` in `model_catalogue`; `rental_contracts.serial`, `events.serial`, `refurbishment.serial`, `resale.serial` in `devices`; `devices.po_number` in `purchase_orders`.
